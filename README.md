# Appai Digital · Inscrições — Atividades do Agito

Protótipo navegável do backoffice **Appai Digital (Gestão de Benefícios)** para o cadastro de atividades do Agito: lista de atividades, cadastro em 4 etapas (Dados gerais → Agendas e vagas → Tags → Revisão e publicação) e acompanhamento de inscrições.

- Arquivo único: `index.html` (HTML, CSS e JavaScript juntos, sem build).
- Dados de exemplo e integrações (CEP, mapa, uploads) são simulados.
- O script do **Useberry** (Live URL) está como último item do `<body>`.

## Publicar no GitHub Pages

1. Em **Settings → Pages**, escolha **Deploy from a branch**.
2. Selecione a branch `main` e a pasta `/ (root)` e salve.
3. Em alguns minutos o protótipo fica disponível em
   `https://diegosantosjob-99.github.io/appaidigital_inscricoes/`.
4. Use esse endereço no teste do tipo **Live URL** do Useberry.

## Abrir localmente

Abra o `index.html` no navegador.
